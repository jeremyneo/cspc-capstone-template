\subsection{Objectives of the Project}

\ChapterContent{
  The main objective of this study is to improve the current inventory process of X university by creating an inventory system with QR code feature. Specifically, the study aims to do the following:

  \begin{enumerate}
        \item Understand the current inventory process and identify the issues of the process.

        \item Design and develop the inventory system based on the requirements of the process.

        \item Evaluate the System Quality using ISO 25010:2023 criteria:
        \begin{itemize}
            \item Functional Suitability
            \item Interaction Capability
        \end{itemize}

        \item Deploy the inventory system for the client to use.

        \item Evaluate the improved inventory process using the following Key Performance Indicators:
        \begin{itemize}
            \item Time Efficiency
            \item Accuracy
            \item Productivity
        \end{itemize}
    \end{enumerate}
}
